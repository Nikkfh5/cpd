# CPD Benchmark for Noise-Induced Transitions

This repository contains code, configuration files, frozen benchmark outputs,
and manuscript-facing reproduction scripts for a controlled comparison of
change point detection methods on generated stochastic trajectories with
level-crossing labels.

The benchmark studies transition-time detection. Trajectories are generated by
the discrete-time stochastic map

```text
x[t + 1] = x[t] + sin(x[t]) * dt + sqrt(D) * error[t]
```

where the innovation sequence is centered and normalized before simulation.
This is the generator used by the repository; it should not be interpreted as a
strict Euler-Maruyama discretization of a continuous-time model.

## Repository Contents

- `algoritms/`: CPD methods and adapters. The directory name is historical and
  intentionally preserved.
- `configs/base.yaml`: generic example/default rerun configuration.
- `configs/fnl_primary.yaml`: manuscript-facing frozen protocol, including
  the primary 25-step matching margin and learned-detector post-processing
  used by the manuscript table.
- `data_source_policy.py` and `DATA_GENERATION_CONTRACT.md`: reproducibility
  checks for generator source, metadata, and allowed parameters.
- `results/kaggle_output_v2/`: frozen primary benchmark outputs used for the
  main manuscript tables.
- `results/publication_same_noise*/`: frozen diagnostic outputs for
  noise-specific Transformer checks and classical baselines.
- `results/matching_margin_robustness_outputs/`: frozen predictions and
  summaries for matching-margin sensitivity figures.
- `scripts/`: table and figure builders for the manuscript-facing artifacts.
- `manuscript/`: FNL manuscript source plus generated tables and figures.

## Environment

Use Python 3.10+.

```bash
python -m pip install -r requirements.txt
```

The manuscript build additionally requires a LaTeX distribution with `pdflatex`
and `bibtex`.

## Quick Verification

Run from the repository root:

```bash
python smoke_test.py
```

Expected output:

```text
Smoke test passed: policy checks and reproducibility are valid.
```

This checks the public generation policy, required metadata fields, allowed
noise types, and deterministic generation under the committed configuration.

## Reproduce Manuscript Tables and Figures

The commands below rebuild the manuscript-facing artifacts from committed
frozen outputs. They do not retrain neural models. The exact manuscript-facing
protocol is documented in `configs/fnl_primary.yaml`; `configs/base.yaml` is a
generic rerun example and should not be treated as the frozen manuscript
configuration.

Primary benchmark tables:

```bash
python scripts/build_publication_tables.py
```

Same-noise diagnostic tables:

```bash
python scripts/build_same_noise_tables.py
```

Compact tables directly included in the manuscript:

```bash
python scripts/build_article_compact_tables.py
```

Figures:

```bash
python scripts/build_publication_figures.py
```

Expected output directories:

- `manuscript/assets/tables/`
- `manuscript/assets/figures/`

The main manuscript uses the frozen outputs in `results/`. The LaTeX source
refers to additional secondary diagnostics as supplementary material; the
supplement source is `manuscript/src/supplementary.tex`.

Build the manuscript PDF:

```bash
cd manuscript/src
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

Expected output:

```text
manuscript/src/main.pdf
```

## Full Evaluation Reruns

The manuscript tables are based on frozen outputs committed under `results/`.
Full evaluation reruns are more expensive and may depend on model weights and
hardware availability. `configs/base.yaml` is a generic example for such reruns,
not the exact frozen manuscript protocol. A typical rerun command is:

```bash
python eval_multi.py --config configs/base.yaml --n-series 50 --output-dir results/eval_multi_rerun
```

Use the frozen outputs for exact manuscript reproduction.

## Main Frozen Result

In the primary `D=1.0`, white-noise scenario with a 25-step matching margin,
the frozen benchmark reports the highest aggregate mean F1 for
`Transformer_v2`. The paired comparison with `LSTM_v2` is not statistically
significant in the committed analysis, so the repository presents the result as
a benchmark observation rather than a universal model-ranking claim.
